# Combined dashboard release — 14 October 2026

This release combines PR28's saved monthly reporting with PR26's paced,
serialized HighLevel imports and compatible runtime/dependency repairs.

## Security dependency repair

The unpatched braces dependency was removed, not ignored or relabelled.
The shadcn CLI is not needed by the running application. Its unmodified
4.21.1 stylesheet is retained in `styles/vendor/shadcn.css` with the MIT license.
This preserves existing utilities and variants without installing its CLI,
MCP server, code generators or glob dependencies.

React, Hooks, accessibility, import and TypeScript checks remain in ESLint
with the same pinned plugins and enabled rules/severities as Next 16.3.8.
[Oxlint's maintained Next.js plugin](https://oxc.rs/docs/guide/usage/linter/plugins.html)
runs 21 existing Next rules at their original severities. The remaining
`no-location-assign-relative-destination` official Next 16.3.8 rule is retained
with its MIT license; only its identity helper was inlined.
`scripts/lint-policy.json` records the prior resolved rules, and tests check
preserved coverage/severities plus actual detection of invalid React, TS,
accessibility, navigation and Next code. Both linters must pass.

No audit threshold, CI gate, authentication boundary or runtime write flag
was weakened. Clean installation and the unchanged audit report zero
vulnerabilities. The full combined application suite passes 353 tests.

## Release acceptance

The exact-head hosted CI, production build/browser checks, database backup
and checksum inspection, ninth migration, existing Worker deployment and
live authenticated verification are required separately. Until each has
completed, this document is preparation, not a production-release receipt.
The ninth migration only creates `LeadRegisterSyncLease`; existing customer
and advertising records are retained. Meta writes remain disabled.

Earlier October 3/14 cloud reports describe their historical blocked states.
This release removes those dependency paths while keeping their gates intact.
