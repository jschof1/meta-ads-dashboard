# PR02: Production-grade Meta read client

Branch: `feat/02-meta-read-client`

Dependency: Complete and merge the preceding implementation PR before marking this ready.

Build a dependable, read-only Meta ingestion client without redesigning the dashboard.

### Required implementation
- Support configurable `META_GRAPH_VERSION`; keep tokens out of logged URLs.
- Cursor-paginate campaigns, ad sets, ads, creatives and insights, with a deliberate safety cap.
- Add safe typed Meta errors, timeouts, bounded transient retries, expired-token/rate-limit handling, trace and usage diagnostics.
- Retrieve account name/currency/timezone plus account-wide entities and creative metadata; campaign filtering is optional.
- Read actual ad-set learning information and use explicit consistent attribution settings.
- Diagnose returned action types; require `META_PRIMARY_RESULT_ACTION_TYPE` when a lead event is ambiguous.
- Isolate and disable existing Meta writes.

### Tests/acceptance
Mock one/multiple pages, >50 ads, no filter/campaigns, token/rate failures, malformed/partial/empty results and missing result event. Diagnostics must retrieve complete account/entity/creative/insight data without a campaign ID; no write path is usable.
