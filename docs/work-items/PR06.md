# PR06: Evidence-based recommendation engine

Branch: `feat/06-recommendation-engine`

Dependency: Complete and merge the preceding implementation PR before marking this ready.

Replace brittle labels with deterministic, inspectable UKTL recommendations.

### Required implementation
- Pure typed analysis functions take config, current/previous/cumulative metrics, status, learning state, series and sample size.
- Return structured signals/recommendations with target, severity, confidence, reason, numeric evidence and proposed action.
- Evidence uses target-relative spend where available, leads, impressions, days active, learning state and historical baselines.
- Implement valid 3/7/14/30-day comparisons; never average ratios incorrectly.
- Fatigue requires combined deterioration; anomalies require minimum samples.
- Implement hold, monitor, possible_tracking_issue, creative_refresh, pause_candidate, scale_candidate and budget_watch.
- Deterministically derive confidence and persist/deduplicate recommendation lifecycle.

### Tests/acceptance
Cover zero/tiny data, winner/loser, false and real fatigue, one-conversion CPL, recovery/decline, tracking failure, paused/new ads and learning. No recommendation lacks inspectable evidence; the same input always gives the same result.
