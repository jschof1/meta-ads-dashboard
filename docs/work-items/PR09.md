# PR09: Approval-gated Meta actions

Branch: `feat/09-approved-meta-actions`

Dependency: Complete and merge the preceding implementation PR before marking this ready.

Allow only narrow, explicitly approved Meta changes.

### Required implementation
- Default `META_WRITES_ENABLED=false`; allowlist pause/resume ad and bounded ad-set daily-budget changes.
- Enforce proposed → explicit approve/reject → executing → executed/failed.
- Before execution verify server auth, feature flag, approval, live target/state, action validity and budget limits; capture old value.
- After execution re-read/verify and persist old/new values, safe Meta reference, ActionLog and final status.
- Prevent duplicate application and hidden non-idempotent retries.
- UI shows exact change, reason, evidence and confidence before approval.
- AI can never directly trigger mutation.

### Acceptance
No generated recommendation reaches Meta without explicit approval and server checks; writes are impossible while disabled. Tests cover auth/flags/approval, stale targets, invalid bounds, duplicate requests and Meta/verification failures.
